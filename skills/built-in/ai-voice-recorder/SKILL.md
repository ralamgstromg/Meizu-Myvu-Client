# AI Voice Recorder Skill

Utiliza esta habilidad cuando el usuario quiera grabar voz, abrir la grabadora de notas de voz IA o iniciar una sesión de grabación.

### Formato de Ejecución
```json
[SKILL: ai-voice-recorder {"action": "open"}]
```
